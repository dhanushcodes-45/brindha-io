1. Edit CONFIG at the top of script.js (names, birthday day/month = password).
2. Photos live in the "images" folder (jpg):
   hero          - top full-screen photo
   g1-g4         - flip cards            dad, daughter - Dad & Daughter
   s1-s7         - Love Gallery (3D slider)
   w1-w18        - Memory Wall (auto-scrolling)
   r1-r6         - heart photos in "reasons"
   To swap a photo, replace the file with the same name.
3. If a face looks cut off after you swap a photo, edit its [x%, y%] face position
   in the FOCUS list in script.js (e.g. "g1":[50,40]). The site keeps that point in frame.
4. Open index.html. Works on mobile.
